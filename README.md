# 寝殿造の垣間見VR

ラーニングテクノロジーⅡ（熊本大学大学院 教授システム学専攻）タスク8-1 の WebVR です。
Unity 6（6000.0 LTS）と WebXR Export（De-Panther, 0.25.0）で作り、WebGL として書き出しました。

平安時代の寝殿造で、碁を打つ姫君の姉妹と、そばで見守る女房たちを、南庭の透垣のきわから垣間見る場面です（『源氏物語絵巻』竹河の垣間見に近い構図。特定の巻の再現ではありません）。
クリック（VR ではコントローラーのトリガー）で、見る位置を「透垣の外」と「御簾の内」で切り替えます。御簾は風にかすかに揺れ、人物はゆっくり動きます。

- 寝殿：母屋 5間×2間に四面の廂、簀子と高欄、南正面の階と階隠、入母屋造・檜皮葺の屋根
- 建具と調度：上げた蔀、帽額・鉤・鉤丸の付いた御簾、壁代、几帳、高麗縁の置き畳、碁盤と碁笥、屏風、二階棚と硯箱、灯台、脇息
- 人物：碁を打つ姉妹（紅葉・女郎花の襲）と、唐衣・裳の正装の女房二人
- 庭：白砂の南庭、萩・薄・女郎花の前栽、松、透垣

寸法は辞典・博物館の公開資料を参考にし、根拠の見つからなかった値（床の高さ・軒の出など）は推測で決めています。

公開ページ：https://taki-0105a.github.io/genji-kaimami-vr/
